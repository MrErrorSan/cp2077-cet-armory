How to use

  

    
Spawn items with CET

    
    
      
  1. Install Cyber Engine Tweaks for your game version.
    2. 
      
  2. In game, press the console key. The default is ~; CET asks you to set it on its first launch.
    3. 
      
  3. Browse and filter the items here, then add the ones you want to the queue.
    4. 
      
  4. Press C or "Copy all commands".
    5. 
      
  5. Paste into the CET console and press Enter.
    6. 
    

    
Weapons without a tier scale with your level when spawned.

    
Some commands on the Cheats tab are marked as broken on the current patch by the sheet itself.

    
Keys

    
Q E switch tab · / search · C copy all · A or Enter add the selected item · arrow keys move between items · X clear queue · G group versions on/off · ESC or right-click: back (close card, then return to categories)

    
Click a category to open it, click an item to see it, double-click to add it to the queue.
